# Demo media

Add your own screenshots or a short GIF showing **both the terminal and the PyBullet window** during a real VLM-controlled run.

Suggested files:

- `demo.gif` — a brief recording of the arm moving the selected cube
- `before.png` — camera view before manipulation
- `after.png` — camera view after manipulation

Update the main `README.md` to display your demo, for example:

```markdown
![Demo of the VLM-guided pick-and-place](assets/demo.gif)
```

Keep large screen recordings outside Git, or link to a hosted video instead.
